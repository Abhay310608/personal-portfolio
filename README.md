# 🌐 Personal Portfolio Website

A responsive personal portfolio showcasing my skills, certifications and projects.

**Tech stack:** HTML · CSS (semantic markup, animations, responsive design)

## Sections
About · Skills · Projects · Certifications · Contact

## Run locally
Just open `index.html` in your browser. No build step needed.

## Deploy free with GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under *Source*, choose branch `main` and folder `/ (root)`, then Save.
4. Your site goes live at `https://YOUR-USERNAME.github.io/personal-portfolio/`.

## Customise
- Replace `YOUR-USERNAME` in the project links inside `index.html` with your GitHub username.
- Colours are CSS variables at the top of `css/style.css`.
